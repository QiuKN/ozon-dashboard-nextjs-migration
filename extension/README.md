# Ozon 选品采集助手

这是当前项目的浏览器扩展部分。它按用户保存的筛选条件自动读取 Ozon 商品详情页和当前已加载的商品列表；列表滚动后也会读取新出现的商品。不读取密码、Cookie 或认证令牌。

## 使用方法

1. 站内下载的最新版已经默认使用 https://ozon-dashboard-nextjs-migration.vercel.app/product-capture；如果使用自定义域名，再打开 extension/config.js 修改 OZON_CAPTURE_APP_URL。
2. 使用 Chrome 116 或更新版本，或基于 Chromium 的 Edge；在扩展管理页开启“开发者模式”。
3. 选择“加载已解压的扩展”，选择本目录的 extension 文件夹。
4. 点击浏览器工具栏中的插件图标，打开 Ozon 选品侧栏；常见一级分类已预置，无需手动输入。
5. 从侧栏多选要包含或排除的分类，再设置品牌、价格、评分和需要保存的字段；访问 Ozon 分类页后，插件会把读到的细分类追加到选项。
6. 在选品网站内输入关键词和数量，点击“开始采集”；Ozon 会在隐藏标签页中打开，浏览器保持运行时会自动滚动并采集，达到数量或列表结束后关闭该页。
7. 打开项目的 /product-capture 页面，队列中的记录会自动导入浏览器本地 IndexedDB。
8. 在选品页筛选、补充备注和标签，然后导出 Excel。

## 数据边界

- 选品记录不写入 Neon、Next.js API 或现有店铺数据。
- 记录只保存在当前浏览器的本地 IndexedDB。
- 清除网站数据或更换浏览器后，本地记录可能消失，请及时导出 Excel。
- 分类选项包含内置的常见一级分类，以及插件从实际访问的 Ozon 页面链接和商品面包屑读取到的细分类。
- 后台任务最多采集 500 件，只滚动当前搜索列表，不会自动切换到其他搜索或分类；浏览器需保持打开。
- 后台任务在浏览器本地运行，不使用 Ozon 账号密码、Cookie 或后台 API。
